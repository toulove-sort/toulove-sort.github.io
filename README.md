# 回想回収ノート（刀剣乱舞・非公式）

GitHub Pagesで公開できる、ブラウザ内保存型の回想回収チェックリストです。

## ファイル
- `index.html` : アプリの画面
- `style.css` : レスポンシブデザイン
- `app.js` : 検索・絞り込み・チェック・保存・JSONバックアップ/復元
- `data.js` : 提供された `回想.csv` から生成した回想データ
- `回想.csv` : 元データ（編集・保管用）

## ローカルで確認する
1. このフォルダ内の `index.html` をブラウザで開きます。
2. ファイルを直接開いた際にブラウザがローカル保存を制限する場合は、VS CodeのLive Serverなどでローカルサーバー経由で開いてください。

## GitHub Pagesで公開する
1. GitHubで新しいリポジトリを作ります（公開設定）。
2. このフォルダ内のファイルをリポジトリのルートにアップロードします。
3. リポジトリの **Settings → Pages** を開き、Build and deploymentを **Deploy from a branch** に設定します。
4. Branchを `main`、フォルダを `/(root)` にして保存します。
5. 表示されたURLからアプリを開きます。

## 保存とバックアップ
- 回収状況はブラウザの `localStorage` に保存されます。サーバーに送信されません。
- PCとスマホの間で自動同期はしません。移行する場合は「JSONを書き出す」でバックアップし、別端末で「バックアップを復元」を使います。
- ブラウザのサイトデータ削除やプライベートブラウズでは、保存が消えることがあります。
- バックアップ復元は、そのブラウザにある現在の回収状況を置き換えます。

## CSVデータの更新
`回想.csv` を更新した場合、同じスキーマで `data.js` を再生成してください。`data.js` の各回想は `id`, `name`, `swords`, `battlefield`, `prerequisiteIds`, `prerequisiteMode` を持ちます。

条件欄の `84/85` はユーザー確認に基づき、ID 84と85の両方が必要なAND条件として登録しています。

## 将来のクラウド同期
保存処理は `app.js` 内の `storage` アダプターにまとめています。将来クラウド同期を追加する場合は、このインターフェースを認証・クラウドデータベース対応の実装に置き換える方針です。公開リポジトリに秘密鍵を置かないでください。

## 注意
非公式ファンメイドツールです。刀剣乱舞ONLINEの公式サービスではありません。回想名・必要男士・合戦場・前提条件は提供されたCSVに基づいています。
